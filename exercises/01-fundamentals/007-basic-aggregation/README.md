# 007 - Basic Aggregation

## Difficulty

🟢 Easy

## Concepts

- `COUNT`
- `AVG`
- `MIN`
- `MAX`
- aggregate functions

## Problem

Return one row containing:

```text
customer_count
order_count
average_product_price
minimum_product_price
maximum_product_price
```

Use the entire database.

## Interview follow-ups

- What does `COUNT(*)` count?
- What is the difference between `COUNT(*)` and `COUNT(column)`?
- How do NULLs affect `AVG`, `MIN`, and `MAX`?
