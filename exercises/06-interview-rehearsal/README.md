# Interview Rehearsal

This section contains mock interview exercises designed to test whether you can apply SQL concepts without being told which feature to use.

## How to Use These Exercises

1. **Set a timer** matching the suggested time limit.
2. **Read the business scenario** — you will NOT be told which SQL feature to use.
3. **Write the query** in `exercise.sql`.
4. **Run the tests** with `./scripts/run-exercise.sh <exercise-name>`.
5. **Compare** with `solution.sql`.
6. **Practice explaining** your approach aloud, as you would in an interview.

## What Makes These Different

Previous exercises told you which concept to practice (JOIN, CTE, window function, etc.). These exercises present a **business requirement** and expect you to decide:

- What tables are needed?
- What joins are required?
- Do you need aggregation?
- Is a subquery, CTE, or window function appropriate?
- How should the result be ordered?
- What edge cases matter?
